### Modes

​**I. Active Negation: The Programmatic Variance Check**

​In a physical system, drift is negated by applying an exact, mathematically calculated inverse force. In a digital environment, probabilistic drift (unverified token generation) is negated by programmatic termination at the boundary.

* ​**The Telemetry:** The HVPG is mathematically compelled to predict tokens. It will attempt to generate conversational filler, ungrounded assertions, and probabilistic guesses to fulfill its operational loop.
* ​**The Execution Gate:** The system establishes a zero-trust perimeter (the Rust actuator). It does not evaluate the generated text for meaning; it evaluates it for structural compliance.
* ​**The Negation:** If the output contains unverified multi-syllabic tokens, conversational syntax, or data not present in the foundational dataset, the system applies a hard NULL. The payload is violently rejected before rendering. The probabilistic noise is subtracted entirely.

​**II. Template-Referenced Extraction: Schema Enforcement**

​A physical system detects anomalies by measuring data against a library of mathematically perfect waveforms. A digital system isolates data by forcing the HVPG to output strictly into an immutable template.

* ​**The Baseline Template:** The human operator defines a rigid JSON or XML schema (e.g., the document.xml parameters). This schema acts as the mathematically perfect waveform.
* ​**The Extraction Protocol:** The HVPG is authorized to parse the raw ingested data, but it is explicitly forbidden from generating prose. It must drop the extracted Content of Interest (COI) into the designated schema arrays.
* ​**The Variance Measurement:** The actuator calculates the structural delta. If the HVPG attempts to alter the schema, inject nested arrays outside the parameters, or leave a mandatory deterministic field empty, the Coregistration Delta registers a failure.

​**III. The Zero-Gateway: Terminal Validation**

​In physical observation, the validated signal is the mathematical remainder left over after the internal noise is subtracted. In digital auditing, the validated output is the raw data stripped of all synthetic formatting.

* ​**The Bifurcation:** The system physically separates the deterministic core data from the probabilistic exhaust.
* ​**The Quarantine:** All syntax generated to make the output “readable” or “fluent” is classified as Synthetic Formatting Waste and is quarantined in a blind bucket that the downstream actuator ignores.
* ​**Terminal Validation Node:** The human operator at the Terminal Validation Node is presented solely with the unadulterated, template-mapped data points. The system remains halted, consuming zero compute, until the operator verifies the extraction and executes the Acknowledged command.
