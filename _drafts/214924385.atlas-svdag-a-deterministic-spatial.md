### Auditing Olympus

Atlas-SVDAG: A Deterministic Spatial Reference Architecture

Edge Compute Neuroimaging

Declan Cooper

Sep 09, 2026

Abstract

The deployment of portable Positron Emission Tomography (PET) to point-of-care environments (such as neurodegenerative, functional, and structural brain disorders), introduces strict thermal, power, and computational constraints. To perform Attenuation Correction (AC) without the physical weight and radiation of a dedicated CT gantry, these systems rely on software-based spatial reference atlases. However, querying dense floating-point spatial volumes exceeds the 15W to 35W thermal design power (TDP) limits of fanless embedded processors, forcing a reliance on non-rigid image deformation and remote computing. This paper introduces Atlas-SVDAG, a zero-dependency C middleware architecture that compresses standard neuroimaging templates into 64-bit Sparse Voxel Directed Acyclic Graphs (SVDAGs). Achieving a 57x reduction in memory footprint, this architecture establishes L3 cache residency, eliminates the algorithmic bias of non-rigid registration, and enables real-time, deterministic pathology tracking at the clinical edge.

1. Introduction: The Compute Bottleneck at the Point of Care

Point-of-care neuroimaging operates under physical parameters distinctly different from those of standard hospital PET/CT installations. Today, dedicated bedside scanners and ambulance-deployed units must maintain system autonomy while operating under strict electrical limits. While detector rings and readout electronics require 100W to 300W, the onboard host compute module must run within a fanless 15W to 35W TDP envelope to preserve sterile clinical airflow.

Neuropsychiatric protocols rely on rapid-decay radiotracers, such as 18F (with a half-life of 110 min). Reconstructing accurate quantitative images from these types of tracers requires calculating the attenuation (absorption) of 511 keV annihilation photons as they travel through the skull and brain tissue.

Without a physical CT scanner to map tissue density, systems must rely on stereotactic spatial reference atlases. Standard templates, such as the MNI152, are distributed as continuous floating-point NIfTI volumes. At an isotropic resolution of 0.5 mm³, a single volume requires about 536.8 MB of uncompressed memory, exceeding the capabilities of low-power embedded processors and forcing the use of workstation-class GPUs.

1.1 The Demographic Mismatch and Algorithmic Bias

In addition to the hardware bottleneck, there is a demographic challenge. Canonical templates are typically generated by averaging the MRI scans of young, healthy adults, whereas the median age for Alzheimer's disease and advanced dementia is often 70 years and older. The aging brain undergoes generalized cerebral atrophy (e.g., the cortex shrinks, and ventricles expand to pool cerebrospinal fluid [CSF]).

Rigidly aligning an atrophied patient scan to a normalized template introduces significant baseline attenuation errors (such as assigning high-density brain tissue values to regions occupied by CSF).

To resolve this, conventional software relies on non-rigid elastic deformations, mathematically warping the patient's anatomy until it conforms to the normative template. Applying non-rigid deformation to, for example, advanced Alzheimer's cases may introduce structural bias into the diagnostic hypothesis. By computationally forcing atrophied tissue to conform to a normal anatomical grid, the algorithm inherently risks minimizing or erasing the morphological features of a pathology.

2. Core Architecture: Sparse Voxel Directed Acyclic Graphs

Atlas-SVDAG addresses these hardware and philosophical constraints by replacing dense volumetric arrays with an anatomically anchored Sparse Voxel Directed Acyclic Graph (SVDAG). This approach maintains a strict separation of concerns (SoC) between baseline anatomy and pathological deviations.

Stereotactic brain space possesses structural properties uniquely suited for graph deduplication:

\* High Bounding-Box Sparsity: Non-brain data accounts for over 80% of the canonical 512³ bounding cube.

\* Homogeneous Tissue Redundancy: Extended sub-volumes of white matter, gray matter, and CSF exhibit identical spatial arrangements across scales.

\* Bilateral Sagittal Symmetry: Structural morphology exhibits contralateral mirroring across the interhemispheric fissure (X = 0).

By encoding the template into a 64-bit dual-word SVDAG, the architecture compresses a standard 536.8 MB floating-point array to roughly 9.4 MB. At this scale, the entire spatial template is designed to reside inside the L3 cache of an embedded x86 or ARM processor (which typically feature 12MB to 32MB pools), reducing ray point traversal latency to 10–15 nanoseconds.

Architectural Comparison Overview

\* Primary Data Structure: Traditional Workstation Registration utilizes a Dense 3D Floating-Point Array, whereas Atlas-SVDAG Middleware utilizes an Anatomically Mapped 64-Bit SVDAG.

\* Memory Footprint: Traditional Workstation Registration requires 536.8 MB for a single template, whereas Atlas-SVDAG Middleware requires ~9.4 MB for its active cache footprint.

\* Primary Hardware Target: Traditionally targets a Multi-Core Server or Discrete GPU, whereas Atlas-SVDAG targets an Embedded CPU L3 Cache.

\* Query Mechanism: Traditionally relies on a Trilinear DRAM Stride, whereas Atlas-SVDAG utilizes a CPU SIMD Integer popcnt.

\* Thermal Ceiling: Traditional systems run between 300W to 2000W+, whereas Atlas-SVDAG operates within a 15W to 35W Fanless Host Compute envelope.

3. The Age-Stratified Reference Library

The 57x memory compression enables a fundamental shift in spatial reference mapping. Instead of relying on a single, universally averaged template, the system stores an Age-Stratified Normal Library.

This library contains 10 to 15 rigidly defined templates categorized by age and natural atrophy progression (e.g., from "45-Year-Old Minimal Atrophy" to "85-Year-Old Severe Atrophy"). Because each SVDAG requires only 9.4 MB, the entire demographic library consumes less than 150 MB of disk storage.

During the initial acquisition phase, the scanner performs a rapid rigid pre-alignment to select the template with the lowest baseline residual. It then loads only that specific 9.4 MB SVDAG permanently into the processor cache. This eliminates the demographic mismatch deterministically, without requiring algorithmic warping.

4. Pathology as a Deterministic Residual (The Delta Stack)

Because the age-stratified base template absorbs the natural variations of aging, dynamic modifications are reserved strictly for acute pathologies. The underlying normative substrate remains permanently rigid.

Exploiting bilateral sagittal symmetry, the DAG evaluates relative uptake asymmetry using the standard Asymmetry Index (AI):

AI(x, y, z) = | I(x, y, z) - I(-x, y, z) | / [ 0.5 \* ( I(x, y, z) + I(-x, y, z) ) ]

This equation normalizes the absolute intensity difference between the left and right hemispheres against the patient's specific metabolic baseline. Normal physiologic variation is bounded at a mean AI of 0.04 (4%). If the AI exceeds a 3-sigma statistical threshold (approx. 13%), the deviation is explicitly recorded into a sparse residual mask.

For acute morphological disruptions (e.g., post-surgical resection cavities in neuro-oncology or severe focal cortical dysplasia), the engine stacks a lightweight Delta SVDAG (under 500 KB) on top of the rigid base atlas. During real-time execution, the CPU queries the Delta overlay first; if the space is empty, execution falls through to the Base atlas. This maps the patient's data hierarchically without altering the underlying coordinate space.

5. Resolving Edge Constraints: Midline Shifts and Scatter Correction

Deploying architectures to the edge requires eliminating all computational ambiguities. Two major processing bottlenecks are resolved deterministically within this framework:

5.1 The Midline Shift: Ray-Space Affine Translation

Severe localized edema (e.g., from a glioblastoma or high-grade brain tumor) can cause a massive physical midline shift. Displacing the interhemispheric fissure across millions of established grid boundaries would normally force the SVDAG octree to subdivide to the leaf level, exponentially increasing memory overhead.

To resolve this, the architecture shifts the integration ray, not the voxels. The header of the Delta SVDAG contains a global affine translation vector (float origin\_mm[3]). During the ray-marching loop, the CPU performs a matrix-vector multiplication to transform the ray's coordinates into the shifted Delta-space. This operation requires 9 Fused Multiply-Add (FMA) instructions, executing in roughly 1 to 2 clock cycles, preserving the extreme sparsity of the Delta mask for a negligible 3-nanosecond compute penalty per step.

5.2 Deterministic Scatter Correction (L1-Resident LUTs)

Up to 60% of detected events in 3D PET are scattered photons. Modern Single Scatter Simulation (SSS) algorithms calculate scattering probabilities using the Klein-Nishina formula, which requires mapping the electron density of the tissue.

Because electron density is highly linearly correlated with physical tissue density, the architecture pairs the C middleware with a static, 256-element Lookup Table (LUT), mapping the 8-bit Tissue Class ID directly to its corresponding electron density value. A 256-element array consumes exactly 1 Kilobyte, ensuring the entire scatter LUT resides permanently in the ultrafast L1 data cache. Querying it is therefore a direct array index operation with zero branching logic, resolving the scatter dependency at virtually zero latency.

6. Physics Validation and Attenuation Error Bounds

Narrow-beam attenuation of 511 keV annihilation photon pairs along a Line of Response (LOR) path L is calculated via the Beer-Lambert law:

P(L) = exp( - SUM [ µ\_i \* Δr\_i ] )

Here, P(L) is the survival probability of the photons, µ\_i represents the discrete linear attenuation coefficient (in cm⁻¹) assigned to each 8-bit tissue class, and Δr\_i = 0.5 mm is the discrete integration step size.

Tissue Class Parameter Profiles

\* Tissue Class ID 0x01 (CSF / Ventricles): Density is 1.0000 g/cm³ | Target µ is 0.0960 cm⁻¹ | Class Variance is ±0.0005 | Max SUV Bias is < 0.4%.

\* Tissue Class ID 0x02 (Brain Parenchyma): Density is 1.0400 g/cm³ | Target µ is 0.0990 cm⁻¹ | Class Variance is ±0.0012 | Max SUV Bias is < 1.1%.

\* Tissue Class ID 0x03 (Subcortical Gray): Density is 1.0500 g/cm³ | Target µ is 0.1005 cm⁻¹ | Class Variance is ±0.0010 | Max SUV Bias is < 0.9%.

\* Tissue Class ID 0x04 (Spongy Bone): Density is 1.4500 g/cm³ | Target µ is 0.1320 cm⁻¹ | Class Variance is ±0.0045 | Max SUV Bias is < 2.1%.

\* Tissue Class ID 0x05 (Compact Cortical Bone): Density is 1.9200 g/cm³ | Target µ is 0.1710 cm⁻¹ | Class Variance is ±0.0060 | Max SUV Bias is < 2.8%.

For a theoretical, worst-case path intersecting 1.5 cm of cortical bone and 15.0 cm of brain parenchyma, the maximum variance sum is 0.027. This translates to an upper bias bound of e^(0.027) ≈ 1.0273 (2.73%), maintaining quantitative accuracy well within accepted clinical diagnostic tolerances (<= 5.0%).

7. Open C-ABI Specification (adag.h)

The C interface guarantees cross-platform binary compatibility. Nodes are serialized into a Little-Endian byte array. Every node consumes exactly 8 bytes (64 bits), structured into two 32-bit words:

\* Word 0 (Bits 0–31) - Structural Topology & Traversal: Bit 31 handles the leaf flag (L); Bits 30–8 control the Child Relative Pointer Offset (23 bits); Bits 7–0 manage the Octant Child Mask (8b).

\* Word 1 (Bits 32–63) - Anatomical Attributes & Gradient Metadata: Bits 63–62 handle Reserved alignment (2b); Bits 61–57 manage Gradient Index (5b); Bit 56 stores the Symmetry flag (1b); Bits 55–40 hold the Anatomical Region ID (16b); Bits 39–32 designate the Tissue Class (8b).

/\* adag.h - C99 Application Binary Interface for Atlas-SVDAG containers \*/

#ifndef ADAG\_H

#define ADAG\_H

#include <stdint.h>

#include <stddef.h>

#define ADAG\_MAGIC 0x47414441 /\* "ADAG" Little-Endian \*/

#pragma pack(push, 1)

/\* 128-byte Cache-Aligned Container Header \*/

typedef struct {

uint32\_t magic; /\* Magic identifier: 0x47414441 \*/

uint16\_t version\_major; /\* Major format version \*/

uint16\_t version\_minor; /\* Minor format version \*/

uint32\_t root\_node\_offset; /\* Byte offset to root node (Default: 128) \*/

uint32\_t node\_count; /\* Total unique 64-bit SVDAG nodes \*/

uint32\_t leaf\_count; /\* Total leaf nodes \*/

float origin\_mm[3]; /\* AC-PC translation vector (X, Y, Z) \*/

float affine\_matrix[9]; /\* 3x3 Rigid/Affine orientation matrix \*/

float voxel\_size\_mm; /\* Isotropic resolution (e.g., 0.5f) \*/

uint16\_t max\_depth; /\* Octree depth (Default: 9 for 512^3) \*/

uint8\_t reserved[50]; /\* Padding to align header to 128 bytes \*/

} adag\_header\_t;

/\* 64-bit Dual-Word Node Layout (8 Bytes, Little-Endian) \*/

typedef struct {

uint32\_t word0; /\* Traversal: child\_mask (8b), child\_offset (23b), leaf (1b) \*/

uint32\_t word1; /\* Payload: tissue (8b), region (16b), sym (1b), grad (5b), res (2b) \*/

} adag\_node\_t;

#pragma pack(pop)

\_Static\_assert(sizeof(adag\_header\_t) == 128, "ADAG Header must be 128 bytes");

\_Static\_assert(sizeof(adag\_node\_t) == 8, "ADAG Node must be 8 bytes");

/\* Deterministic Shift-and-Mask Bit Extraction \*/

#define ADAG\_GET\_CHILD\_MASK(w0) ((uint8\_t)((w0) & 0xFFu))

#define ADAG\_GET\_CHILD\_OFFSET(w0) ((uint32\_t)(((w0) >> 8) & 0x7FFFFFu))

#define ADAG\_IS\_LEAF(w0) ((uint8\_t)(((w0) >> 31) & 0x1u))

/\* Fall-Through Dual Traversal (Base Atlas + Sparse Delta Overlay) \*/

static inline const adag\_node\_t\* adag\_traverse\_stacked(

const adag\_node\_t\* base\_node,

const adag\_node\_t\* delta\_node,

uint8\_t octant)

{

// 1. Check Delta Overlay first

if (delta\_node != NULL) {

uint8\_t d\_mask = ADAG\_GET\_CHILD\_MASK(delta\_node->word0);

if (d\_mask & (1u << octant)) {

uint8\_t d\_lower = d\_mask & ((1u << octant) - 1);

return delta\_node + ADAG\_GET\_CHILD\_OFFSET(delta\_node->word0) + (uint32\_t)\_\_builtin\_popcount(d\_lower);

}

}

// 2. Fall-through to Base Atlas

if (base\_node != NULL) {

uint8\_t b\_mask = ADAG\_GET\_CHILD\_MASK(base\_node->word0);

if (b\_mask & (1u << octant)) {

uint8\_t b\_lower = b\_mask & ((1u << octant) - 1);

return base\_node + ADAG\_GET\_CHILD\_OFFSET(base\_node->word0) + (uint32\_t)\_\_builtin\_popcount(b\_lower);

}

}

return NULL;

}

#endif /\* ADAG\_H \*/
